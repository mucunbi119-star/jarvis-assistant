# 自分の名前と声で使う、日本語アシスタント

Windows の自分の PC で起動する、黒と青を基調にした日本語アシスタントです。画面はブラウザで開き、会話・設定・記憶・資料は PC 内に保存します。API キーがなくても、**「デモ」と表示した画面とサンプル回答**で操作を試せます。

最初はデモで使い、必要になった機能だけ外部サービスに接続してください。映画のロゴ・映像・声は使用していません。

## 1. 最初に準備するもの

- Windows 10 / 11 とインターネット接続（インストール時）。
- [Python 3.11 以降](https://www.python.org/downloads/windows/)。インストール時に **Add python.exe to PATH** を選んでください。
- Google Chrome または Microsoft Edge。音声はブラウザと Windows に入っている日本語の声に依存します。
- このチャットで渡す Windows 用 ZIP、または公開後のリポジトリのファイル一式。ZIP を右クリックして **すべて展開**してください。GitHub から受け取る場合は、実装コードを保存したブランチの ZIP を取得してください。

Node.js、Docker、OpenAI API キー、Google アカウントは、デモを起動するだけなら不要です。

## 2. インストールして起動する

1. 展開したフォルダにある **start.bat** をダブルクリックします。初回は自動で準備を始め、専用の `.venv` フォルダを作り、必要なライブラリを入れます。数分かかる場合があります。
2. 「準備ができました」と表示されたら、何かキーを押して続けます。2回目以降は準備済みの環境から起動します。ライブラリを更新するときは **setup.bat** を実行してください。
3. 起動を確認してからブラウザが開きます。最初の画面で AI の名前と、自分の呼び方を設定してください。
4. 終了するときは、起動した黒い画面で **Ctrl+C** を押します。ブラウザのタブを閉じるだけではサーバーは終了しません。

自動でブラウザが開かない場合、PC 内の `http://127.0.0.1:8765` を開いてください。このアドレスは自分の PC 専用です。共有サーバーへの公開や、インターネットからの接続には対応していません。

開発者がコマンドで起動する場合：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe scripts\run.py
```

Linux / macOS でサーバー部分を確認する場合：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/run.py --no-browser
```

Windows の Chrome・アプリ起動機能の確認には Windows が必要です。

## 3. 名前・話し方・声を変える

**設定**で AI の名前、自分の呼び方、話し方、回答の長さを変更し、保存します。名前は画面タイトルと応答に使います。名前を呼ぶだけで録音を始める機能はありません。

声は **日本語に対応し、今のブラウザで実際に見つかった声**から選びます。「試聴」で短いサンプルを再生でき、速度・音量・自動読み上げを変更できます。「読み上げ停止」で途中停止できます。声が表示されない場合は、Windows の **設定 → 時刻と言語 → 言語と地域**から日本語の音声機能を追加し、ブラウザを再起動してください。

マイクは対応ブラウザでマイクボタンを押したときだけ開始します。初回の説明とブラウザのマイク許可を確認し、停止ボタンで終了してください。常時録音はしません。**音声認識はブラウザのサービスに音声を送信する場合があります。**利用できない場合も、テキスト入力は続けられます。ブラウザの音声機能には、このアプリから OpenAI 音声 API の料金は発生しません。OS・ブラウザの音声が必ずローカル処理になるとは限りません。

## 4. 実際の AI に接続する（任意・従量課金）

1. [OpenAI の API プラットフォーム](https://platform.openai.com/)で、自分の API 利用設定・支払い設定・キーを用意します。このアプリは契約や課金設定を自動で行いません。
2. `.env.example` をコピーし、コピーを **.env** という名前にします。エクスプローラーの **表示 → ファイル名拡張子**を有効にし、`.env.txt` になっていないことを確認してください。
3. `.env` をメモ帳で開き、`OPENAI_API_KEY=` の右に自分のキーを入力して保存します。このファイルやキーは他人に送らないでください。
4. アプリを一度終了し、`start.bat` で再起動します。設定でデモから実サービスに切り替えます。

```dotenv
OPENAI_API_KEY=ここに自分のキー
OPENAI_MODEL=gpt-4.1-mini
```

キーはサーバーだけが読みます。画面の設定欄にキーを入力する必要はありません。API を使うと、質問、直近の会話、設定した呼び方・話し方、回答に使う記憶、選択した資料の関連抜粋、検索・ページの取得テキストが OpenAI へ送られます。詳しくは [データと外部送信](docs/PRIVACY.md)を確認してください。

**ChatGPT の月額契約と OpenAI API の料金は別です。**検索ツールにも別料金が発生する場合があります。固定の金額は表示していません。[OpenAI の公式料金](https://openai.com/api/pricing/)を確認し、利用上限を設定してください。キー未設定・通信失敗を、実際の AI の成功として表示することはありません。

## 5. Web 調査・資料・表

Web 調査では、実際に取得できた出典と調査日時を確認してください。デモ結果には「デモ」と表示し、実際の検索結果と区別します。日時の初期設定は `Asia/Tokyo`（日本時間）で、設定から変更できます。ページが取得できない場合や抜粋しか読めない場合は、その状態を表示します。

**資料**に TXT・CSV・文字を抽出できる PDF・Excel（`.xlsx`）を読み込めます。古い `.xls`、パスワード付きファイル、画像だけの PDF の OCR は対象外です。資料を選んで質問すると、関連箇所と参照位置を使います。資料を削除すると、保存した原本と検索用データを削除します。選択前に、資料を外部へ送信してよいか確認してください。

**作成ファイル**では表を確認し、Excel と日本語向け CSV（UTF-8 BOM 付き）を保存できます。Excel には編集できるグラフも出力します。元ファイルは上書きしません。外部由来の文字列が意図せず Excel の数式になることを防いでいます。値の不明・推定・単位・期間は、自分でも確認してから使ってください。実サービスの会話で「動画編集ソフトを調べて、料金と特徴をExcelにまとめて」のように依頼すると、回答の調査後に表へ整形し、ファイルを作成します（APIを追加で1回呼び出すため、その分の料金も発生します）。整形できなかった場合は、回答本文を残して失敗を表示します。

CSVの月別集計は、表を読み込み、集計する日付列と数値列を指定し「日付を月ごとにまとめる」を選びます。年を含む日付が必要です。グラフのX列・Y列は0から始まる番号で指定します。

## 6. Chrome・ChatGPT・Google 連携

詳細な設定は [外部連携の手順](docs/INTEGRATIONS.md)を参照してください。

- Chrome はアシスタント専用のプロファイルで起動します。普段の Chrome の履歴・保存パスワードは読み取りません。ログインは自分で行ってください。
- ChatGPT の Web 画面と、アシスタント自身の OpenAI API 応答は別です。Web 画面の自動送信・回答取得を公式に利用できる連携として保証できないため、**ChatGPT を開き、表示した文章を自分で貼り付ける方式**です。自動送信や回答の読み取りは未実装です。
- Google スプレッドシートは公式 OAuth を使います。Google Cloud で **Google Sheets API** と **Google Drive API** を有効化し、OAuth 同意画面と **デスクトップ アプリ**用クライアントを用意します。JSON をリポジトリの外に置き、`.env` の `GOOGLE_CLIENT_SECRETS_FILE` に絶対パスを設定して再起動してください。その後、画面の Google 接続から自分のアカウントを許可します。
- Google は `drive.file` 権限で、このアプリが作成したファイルを扱う構成です。自分の全スプレッドシートに一括アクセスする権限は要求しません。任意の既存シートを選んで認可する Google Picker は未実装です。
- Google への送信・既存シートの更新前に、対象と内容を確認してください。未接続でも Excel・CSV は保存できます。
- アプリとフォルダの起動対象は、ユーザーが登録したものだけです。AI が書いた任意のコマンドは実行しません。

## 7. 保存場所と削除

初期状態では、このフォルダ内の **data** に保存します。会話・設定・長期記憶はデータベース、資料・作成ファイル・専用 Chrome プロファイル・Google 認証はそれぞれ別に管理します。正確な保存先と外部送信は [データと外部送信](docs/PRIVACY.md)に記載しています。

会話、長期記憶、資料は画面から対象を確認して削除できます。会話を削除しても別に保存した記憶は残るため、記憶も消したい場合は **記憶**で削除します。全ローカルデータを消す場合は、アプリと専用 Chrome を終了し、必要なファイルを退避してから `data` フォルダを削除します。この操作は元に戻せません。`.env` の API キーは別なので必要に応じて削除・失効してください。Google 側の認可取り消しは、Google アカウントの接続管理からも行ってください。

バックアップはアプリ終了中に `data` をコピーします。バックアップにも会話や Google トークンなどの個人情報が含まれるため、公開しないでください。

## 8. よくあるエラー

| 表示・症状 | 次にすること |
| --- | --- |
| Python が必要と表示される | Python 3.11 以降をインストールし、setup.bat を再実行します。 |
| ライブラリのインストールに失敗 | インターネット接続と会社・学校のプロキシを確認します。証明書検証を無効にせず、エラーを確認してください。 |
| ポート 8765 が使用中 | 以前起動した黒い画面で Ctrl+C を押します。複数起動しないでください。 |
| ブラウザが開かない | 黒い画面のエラーを確認し、起動済みなら `http://127.0.0.1:8765` を手動で開きます。 |
| API キー未設定 / 認証失敗 | `.env` の名前、キー、API の利用設定を確認して再起動します。キーを質問文に貼らないでください。 |
| 利用制限・残高・モデルのエラー | OpenAI API の利用状況、モデルの利用権限、上限を確認します。ChatGPT の契約とは別です。 |
| マイク・声が使えない | ブラウザの権限、日本語音声の追加、Chrome/Edge の更新を確認します。テキストは引き続き使えます。 |
| PDF を読み込めない | 文字を選択できる PDF か確認します。画像 PDF は先に別の OCR ソフトで文字化してください。 |
| Chrome を操作できない | Windows に通常版 Google Chrome がインストールされているか確認します。専用プロファイルを別のウィンドウで重複使用しないでください。 |
| Google に接続できない | OAuth クライアントがデスクトップ用か、Sheets/Drive API が有効か、テストユーザーが登録されているかを確認します。 |

問題を相談するときは、エラーの文章だけを共有し、API キー・認証コード・資料の内容・Google の JSON は送らないでください。
