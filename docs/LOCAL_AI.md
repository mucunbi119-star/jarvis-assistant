# API 利用料なしで、ローカル AI を使う

このモードでは **Ollama** と PC に保存したモデルで回答を生成します。OpenAI API キーは不要です。モデルが起動できない場合や検索が失敗した場合に、有料 API へ自動で切り替えることはありません。

ローカル AI は定型文のデモとは異なり、その場で回答を作ります。ただし誤りはあり得ます。特に小型モデルの表・計算・最新情報は、元の資料や出典でも確認してください。

## 1. Ollama をインストールする

1. アシスタントを起動して、左下の **設定**を開きます。
2. ローカル AI の案内から、[Ollama 公式の Windows ダウンロード](https://ollama.com/download/windows)を開きます。
3. 公式インストーラーを自分で実行し、完了後に Windows のスタートから **Ollama** を起動します。ローカルモデルの利用に、サインインや有料契約は不要です。

Ollama の公式要件は Windows 10 22H2 以降です。インストール本体用に少なくとも 4 GB、さらにモデルの保存場所が必要です。このアプリの初期モデルは **qwen3:4b** で、数 GB のダウンロードが発生します。準備の目安として、メモリ 8 GB 以上、空き容量 10 GB 以上を確保してください。これは動作保証ではなく、OS・他のアプリ・選ぶモデルによって必要量と速度が変わります。映像編集ソフトを同時に開くと、特にメモリが不足しやすくなります。

## 2. モデルをダウンロードする

1. アシスタントの設定で、ローカル AI の状態を確認します。
2. 初期モデル **qwen3:4b** のダウンロードボタンを押し、モデル名・保存容量・通信が発生することを確認して開始します。
3. ダウンロードが完了したら状態を更新し、利用可能なモデルを選びます。

ダウンロードは回線によって数分以上かかります。中止しても取得途中のデータが Ollama 側に残り、次回の取得で再利用される場合があります。アプリはインストーラーを自動実行せず、会話を始めただけでモデルを勝手にダウンロードしません。

ボタンで準備できない場合は、新しく開いた Windows ターミナルで次を実行する方法もあります。

```powershell
ollama pull qwen3:4b
```

`ollama` が見つからない場合は、Ollama のインストール後にターミナルを閉じて開き直してください。

## 3. 「ローカル AI」で会話する

設定の **利用モード**で **ローカル AI** を選び、保存します。画面のモード表示を確認してから、「自己紹介して」「30秒の動画の構成を考えて」などと入力してください。

Ollama が終了している、モデルがない、メモリ不足などの場合はエラーを表示します。定型文や有料サービスの返答に置き換えて、成功したように表示することはありません。初回のモデル読み込みや CPU での生成は時間がかかる場合があります。

## 4. インターネットから情報を調べる

**Web 調査**画面を使うか、会話で「最新の情報を調べて」と依頼します。質問の内容に応じて検索を使い、取得した文章を PC 内の AI が要約します。特定の公開 URL の要約も利用できます。

このモードの検索は、DuckDuckGo の公開 HTML 検索ページを取得する方法です。**公式の検索 API や、無制限の検索サービスではありません。** CAPTCHA、アクセス制限、ページ形式の変更などで使えない場合があります。その場合は検索失敗を表示し、通常のブラウザで検索する方法を案内します。有料の検索 API には切り替えません。

回答の出典には、実際に取得したページのタイトル・URL・調査日時を表示します。検索結果の抜粋しか確認できなかった場合は、本文未確認と表示します。情報が見つからない場合に、架空の調査結果や出典を作りません。ログイン・アクセス制限は回避しません。

検索語は DuckDuckGo に、ページ取得のアクセスは各サイトに送信されます。**ローカル AI モードでも、Web 検索まで完全オフラインになるわけではありません。** 会話履歴・記憶・選択資料の抜粋は、回答生成のために PC 内の Ollama に渡します。

## 費用と、有料モードとの違い

| 利用方法 | このアプリからの API 利用料金 |
| --- | --- |
| デモ | なし。実際の自由な回答や Web 検索はしません。 |
| ローカル AI と公開ページの検索 | 有料 API を呼びません。電気代、モデルの保存容量、回線の通信量は必要です。 |
| 有料 API モード | OpenAI API の利用に応じた料金が発生します。明示的な設定・切り替えが必要です。 |

有料 API モード用のキーが `.env` に残っていても、ローカル AI モードから OpenAI に自動接続することはありません。利用モードの表示を確認してください。

## Ollama 自体のクラウド機能も無効にする場合

このアプリはローカルの Ollama とローカルモデルだけを使い、クラウドモデルを選べないようにしています。さらに Ollama 自体をローカル専用にするには、Windows の **「環境変数を編集」→ ユーザー環境変数**に、名前 `OLLAMA_NO_CLOUD`、値 `1` を設定し、Ollama を完全に終了して再起動してください。

これは Ollama 側の設定です。アシスタントの `.env` に同じ文字列を書くだけでは、すでに動いている Ollama の設定は変わりません。既存の設定ファイルを手作業で上書きする必要はありません。詳細は [公式 FAQ](https://docs.ollama.com/faq#how-do-i-disable-ollama-cloud-features)を参照してください。

ブラウザの音声認識・読み上げは別機能です。ローカル AI にしても、ブラウザが音声サービスに送信する場合があります。

## 保存先と、旧版からの引き継ぎ

アシスタントの会話・設定・記憶・資料は、これまでと同じ `data` に保存します。Ollama のモデルは別で、Windows の標準保存先は **`C:\Users\ユーザー名\.ollama\models`** です。アシスタントの `data` を消しても、Ollama のモデルは消えません。モデル削除は Ollama の管理画面、または対象を確認して `ollama rm モデル名` で行います。

新版 ZIP は旧版と別のフォルダに展開してください。過去の会話を引き継ぐ場合は、アシスタントと専用 Chrome を終了し、旧版の `data` をバックアップしてから、新版の同じ場所へコピーします。新版ですでに会話を作った場合は、その `data` も退避し、どちらを残すか選んでください。データベースの自動マージはありません。`.venv` はコピーせず、新版の `start.bat` で準備します。`.env` や Google 認証を不用意に上書きしないでください。

## うまく動かない場合

| 状態 | 確認すること |
| --- | --- |
| Ollama に接続できない | Windows のスタートから Ollama を起動し、設定の状態確認をやり直します。 |
| モデルがない | qwen3:4b のダウンロード完了を待ち、状態を更新して選びます。 |
| ダウンロードが止まる | 空き容量、回線、Ollama の状態を確認します。証明書検証は無効にしません。 |
| 回答が遅い・メモリ不足 | 編集ソフトなどを閉じて試します。PC に適した、より小さいローカルモデルを別途準備する方法もあります。 |
| 検索だけ失敗する | 検索先の制限や仕様変更の場合があります。ブラウザでの検索や、公開 URL を直接指定する方法を使います。 |
| まだ定型文しか出ない | 利用モードが「デモ」か確認し、「ローカル AI」を選んで保存します。 |

実装と検証できた範囲は [実装状況](STATUS.md)に記録しています。Windows 実機や実際のモデル生成を確認したかどうかは、自動テストとは分けて記載します。
