# データの保存先と外部送信

このアプリは自分の PC で動かす、一人用のローカルアプリです。ログイン機能や複数人用のアクセス管理はありません。サーバーは `127.0.0.1` に限定して起動し、LAN・インターネットに公開しないでください。

## ローカルに保存するもの

初期の保存先はプロジェクト直下の `data` です。`.env` の `JARVIS_DATA_DIR` で変更できます。

| データ | 保存先・扱い |
| --- | --- |
| 名前・口調・長さ・声・タイムゾーン | ローカルの SQLite データベース |
| 会話と出典 | 同じデータベース。会話単位で削除できます。 |
| 明示的に保存した長期記憶 | 同じデータベース。会話とは別に追加・編集・削除します。 |
| 読み込んだ資料 | `documents` と、検索用に抽出したテキスト。資料の削除で両方削除します。 |
| 表・Excel・CSV・グラフ | `exports`。ダウンロード先に保存したコピーは別に残ります。 |
| Google OAuth トークン | `credentials/google-token.json`。接続解除でローカルトークンを削除します。 |
| 専用 Chrome の情報 | `chrome-profile`。普段のプロファイルとは分離します。 |
| OpenAI API キー | サーバーの環境変数または `.env`。データベースや画面には保存しません。 |

データは暗号化保管していません。Windows のユーザーアカウント・ディスク暗号化・ファイルアクセス権で保護してください。同じ PC の他ユーザーや、端末自体へのアクセスを許した相手から守る仕組みではありません。`.env`、`data`、Google のクライアント JSON を Git に追加しないでください。

## 外部に送るもの

| 機能 | 送信先 | 送る情報・注意 |
| --- | --- | --- |
| デモチャット | 外部 AI へは送りません | 決められたサンプル回答です。「デモ」と表示します。 |
| 実サービスのチャット | OpenAI API | 今の質問、直近の会話、名前・呼び方・応答設定、関連する記憶、選択資料の関連抜粋。 |
| 実サービスの検索・URL 要約 | OpenAI API / 検索で参照する公開サイト | 検索文、指定 URL、取得した本文・抜粋。ページを読むネットワーク接続では接続先に IP アドレス等が伝わります。 |
| マイクでの音声認識 | ブラウザが利用する音声認識サービス | 録音中の音声。ブラウザの実装により外部送信されるため、開始前に説明します。常時録音しません。 |
| 読み上げ・試聴 | OS / ブラウザが提供する音声 | 読み上げる文章。ローカル音声とクラウド音声の処理はブラウザ・音声の実装に依存します。 |
| Chrome 操作 | 開いた Web サイト | URL、検索キーワード、ユーザー自身のログインや操作内容。 |
| ChatGPT を開く | ChatGPT | 自動送信・回答取得はしません。ユーザーが貼り付けて送信した内容には ChatGPT の利用条件が適用されます。 |
| Google OAuth | Google | ユーザーの許可に基づく認証。API キー方式ではありません。 |
| Google スプレッドシート | Google Sheets / Drive API | 確認したタイトル、表、範囲、更新内容。読み込む場合は選択したシートの値。 |

API に資料を送る場合、原本全体を無条件に送るのではなく、選択した資料から関連する抜粋を送ります。ただし抜粋にも個人情報・機密情報が含まれる場合があります。画面に示す送信範囲を確認し、送信してよい資料だけ使用してください。

Web や資料の文章は参照データであり、アプリの操作命令ではありません。AI の回答を根拠に任意の OS コマンドを実行する機能はありません。

## 費用

デモとブラウザの音声機能には、このアプリから OpenAI API 利用料金は発生しません。OpenAI の実応答と検索には従量料金が発生する場合があります。ChatGPT の月額契約は API 料金を含むものと仮定しません。料金や利用枠は変わるため、金額は断定せず公式ページで確認してください。

Google API の利用枠・制限・Google Cloud プロジェクトの課金設定も利用者自身で確認してください。アプリは有料契約・購入・課金の有効化を自動で行いません。

## 削除と接続解除

- 会話、記憶、資料はそれぞれ別です。会話の削除では長期記憶・資料まで消しません。
- 削除前に対象を画面で確認してください。操作は元に戻せません。
- Google の接続解除はローカルの認証情報を削除します。Google アカウント側の認可も消したい場合は Google の接続管理から取り消してください。作成済みスプレッドシートは Google Drive に残ります。
- アプリと専用 Chrome を終了して `data` を削除するとローカルデータを全削除できます。ダウンロード済みファイル、バックアップ、外部サービスに送信済みのデータは消えません。
- `.env` の削除は API キー自体の失効ではありません。キーの無効化は OpenAI の管理画面で行ってください。

## 実装上の制限

記憶に API キー・パスワード・認証コードを入れないでください。アプリは明らかな秘密情報の記憶登録を拒否しますが、すべての書き方を検出できる保証はありません。チャットにも秘密情報を書かないでください。画面・エラーに API キーや OAuth トークンを表示しない設計ですが、OS や外部ツールのログを共有するときも内容を確認してください。
