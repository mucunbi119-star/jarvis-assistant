Python を起動できませんでした

Python が未インストール、古いバージョン、または起動用の設定が見つからない可能性があります。アシスタントの会話画面はまだ起動していません。この案内だけなら Python なしで開けます。

1. Python を準備する

Python 公式の Windows ダウンロードを開く ↗

Python 3.11 以降が必要です。通常の Windows PC なら、サポート中の Python 3.14 または 3.13 の Windows installer (64-bit) を選べます。インストール時に 「Add python.exe to PATH」 があればチェックしてから進めてください。ARM 搭載 PC は対応する ARM64 版を選んでください。

Python install manager を選んだ場合、管理ツールを入れただけでは実行用 Python がないことがあります。管理ツールの案内に従って Python 本体もインストールしてください。管理ツールが導入済みなら、新しく開いたターミナルで py install 3.14 を実行して準備できます（ダウンロードが発生します）。

このアプリが Python のインストーラーを自動実行することはありません。公式サイト・インストーラーの発行元を確認して、ご自身で操作してください。

2. アシスタントをもう一度起動する

  1. インストールが完了したら、前の黒い起動画面を閉じます。
  2. アシスタントのフォルダ内にある start.bat をダブルクリックします。
  3. 必要なライブラリの準備後、何かキーを押すと会話画面がブラウザで開きます。

起動ファイルのメッセージは Windows の文字コード問題を避けるため英語です。手順はこの日本語ページと README.md を参照してください。

すでに Python を入れている場合

Windows のスタートを右クリックして「ターミナル」を開き、py --version と python --version をそれぞれ実行し、表示された文章を確認してください。3.11 以降が表示されても進めない場合は、その結果を相談してください。パスワードや API キーは入力・共有しないでください。

このページは PC 内の説明ファイルです。会話・資料のアップロードは行いません。
